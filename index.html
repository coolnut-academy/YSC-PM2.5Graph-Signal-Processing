Research problem

Mathematical core

คณิตศาสตร์เป็นแกน — เว็บเป็นเพียง PoC

ลำดับการทำงานต้องเริ่มจาก model และ sampling strategy ก่อนจึงนำผลมาสื่อสารผ่านเว็บ

STEP 01

สร้างกราฟ

สถานีเป็นโหนด และความสัมพันธ์ระหว่างสถานีเป็นน้ำหนักของ edge

G=(V,E,W)
STEP 02

Graph Laplacian

แปลงโครงสร้างเครือข่ายไปสู่ฐานเชิงสเปกตรัมผ่าน eigendecomposition

L=D−W,L=UΛUT
STEP 03

Low-frequency model

ตรวจสอบก่อนว่าสัญญาณ PM2.5 มีโครงสร้าง smooth เพียงพอ ไม่สมมติ bandlimited อัตโนมัติ

x≈Urα
STEP 04

Sampling

เลือกเซต S ภายใต้ K เดียวกัน แล้วเก็บค่าที่สังเกตได้ผ่าน sampling matrix

y=CSx
STEP 05

Reconstruction

สร้างค่าทั้งเครือข่ายกลับ แล้วเปรียบเทียบเฉพาะจุด held-out กับ ground truth จริง

x^=Ur(CSUr)†y
Research questions

4 คำถามหลักที่เว็บต้องช่วย “มองเห็น”

RQ1

Sensor Budget

เมื่อ K เท่ากัน วิธีใดให้ reconstruction error ต่ำที่สุด?

RQ2

Graph Construction

Distance, elevation, historical correlation หรือ hybrid graph ส่งผลต่อ error ต่างกันอย่างไร?

RQ3

Data-loss Robustness

เมื่อสูญเสียข้อมูล q จุด วิธีใดรักษาความแม่นยำได้ดีกว่า?

RQ4

Geometry vs Information

การกระจายสถานีให้ทั่วเชิงพื้นที่ สอดคล้องกับการรักษาข้อมูลเชิงสเปกตรัมมากเพียงใด?

Experimental integrity

ออกแบบให้ผล “ตรวจสอบได้” ไม่ใช่แค่ภาพสวย

Research Mode ต้องเริ่มจากสถานีที่มีค่าจริงสำหรับ validation และป้องกัน data leakage ตั้งแต่ต้น

Temporal split

1
Past / Graph periodสร้าง W และ historical correlation โดยไม่เห็นข้อมูล test
2
Validation periodเลือกพารามิเตอร์ เช่น σ, r หรือ graph formulation
3

4
Failure experimentตัดข้อมูลบาง sensor แล้ว reconstruct ซ้ำภายใต้ protocol เดียวกัน

Scope & originality

วางตำแหน่งความใหม่ให้ “ตรงและปลอดภัย”

WHAT THIS PROJECT IS

Applied & Computational Mathematics

ความใหม่อยู่ที่การออกแบบการศึกษาเชิงระบบสำหรับบริบทเครือข่าย PM2.5 ของประเทศไทย—not claiming a new GSP theory.

  • เปรียบเทียบ Random / Coverage / GSP / Robust GSP ภายใต้ K เดียวกัน
  • ศึกษาผลของ graph construction ต่อ reconstruction
  • วัด trade-off ระหว่าง geometry, spectral information และ robustness
  • ใช้ webapp เพื่อ reproduce และสื่อสาร mathematical experiment
WHAT THIS PROJECT IS NOT

ไม่ใช่ระบบเตือนภัย PM2.5 แบบเวลาจริง

และไม่ใช่การอ้างว่าเป็นผู้คิด Graph Signal Sampling หรือ Robust GSP ขึ้นใหม่

  • ไม่สร้างตัวเลขผลการทดลองก่อนมีข้อมูลจริง
  • ไม่ใช้ UI เป็นหลักฐานว่าคณิตศาสตร์ทำงาน
  • ไม่ใช้ข้อมูล test เพื่อสร้าง correlation graph
  • ไม่บังคับ methodology ให้ตามความสวยของเว็บ
